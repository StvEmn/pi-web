# 04: 标签栏交互完善

**What to build:** 标签栏的日常操作手感补齐：右键任意 tab 弹出菜单（关闭 / 关闭其他 / 关闭右侧），键盘用户用 Menu/Shift+F10 也能打开；tab 数量超宽时各 tab 收缩、标题截断省略号、悬停 tooltip 显示完整标题与 cwd；当已开 tab 横跨 ≥2 个项目时标题前显示项目名前缀，单项目时不显示；正在运行的会话 tab 有可见运行指示；tablist 支持方向键切换；窄屏不破版。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 右键菜单：关闭/关闭其他/关闭右侧三动作，焦点管理正确（打开聚焦首项、Esc 关闭归还焦点）、Menu/Shift+F10 键盘可达
- [ ] close-others / close-right 转移进状态模块并有单测（相邻选择策略复用 01 的左优先规则）
- [ ] 溢出收缩：超宽收缩+省略号+tooltip 全名与完整 cwd；单行不换行不横滚
- [ ] 条件项目前缀：跨 ≥2 项目时显示项目名前缀，单项目时隐藏（纯函数计算有单测）
- [ ] 运行指示：tab 上对运行中会话显示微标点（数据来自现有 running 轮询）
- [ ] tablist 方向键左右切换、Home/End 到首尾；aria-selected 同步
- [ ] 窄屏：不破坏现有响应式断点，允许简单收纳
- [ ] e2e：右键三动作、溢出态、跨项目前缀出现/消失
